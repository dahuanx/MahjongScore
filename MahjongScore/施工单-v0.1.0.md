# 麻将计分器 v0.1.0 施工单 · App 联机版

日期：2026-10-28
服务端：mjserver v0.1.0（已上线，ws://182.92.191.33:9100/ws）

## 一、本轮内容（v0.1 联机版）

| 模块 | 内容 |
|---|---|
| 大厅 | 昵称设置（记住）、本机识别号自动生成、创建房间（自动 5 位房号）、输房号加入 |
| 对局屏 | 四人分数卡（2×2，红赢绿亏，绿点=在线）、连接状态灯、断线自动重连（3 秒/次，流水不丢） |
| 记分 | 记一局：选赢家/输家/点炮或自摸/分值；房主可撤销最近一局 |
| 流水 | 逐局列表（第几局、谁赢谁输、分值、方式、时间） |
| 合规 | 纯积分记账，无资金、无第三方 SDK、无数据上传（除自家服务器记分） |

## 二、技术要点

- Kotlin 2.0.20 + Jetpack Compose（Material 3），minSdk 26（Android 8.0+）
- OkHttp WebSocket 直连 `ws://182.92.191.33:9100/ws`，kotlinx-serialization 解析
- 断线重连：重发 join，服务端回全量 state 对账
- 个人识别号：本机 SharedPreferences 存 12 位 UUID，换手机不带走的记录在各自手机上（v0.3 做导出）

## 三、交付物

- 源码：`MahjongScore/` 工程

## 四、验证建议（四人实测流程）

1. 四台手机安装 APK，各自打开填昵称
2. 一台点「创建房间」，报出 5 位房号；其余三台输房号加入
3. 房主记一局：选赢家、输家、点炮、8 分 → 四台手机分数卡应同时刷新（赢家 +8 红，输家 -8 绿）
4. 记错 → 房主对最近一局点「撤销」→ 四端分数归零
5. 杀掉一台手机 App 再打开输房号重进 → 分数与流水应完整恢复
6. 开飞行模式 10 秒再关 → 顶栏红点转绿，分数不乱
7. 第五人尝试加入 → 提示房间已满

## 五、已知边界（留到后续版本）
